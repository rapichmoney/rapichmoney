## OSTROVOK

Dynamic Island как на iPhone — на компьютере с Windows. Бесплатно и с открытым исходным кодом.

Музыка, обложки, текст песни, уведомления, буфер обмена и Discord Rich Presence в небольшом острове у края экрана.

VPN-клиент для Windows с отдельным управлением zapret. Импорт профилей, выбор сервера и маршруты для приложений и сайтов.
